Applications that run on WSGI
=============================

`MoinMoin <https://www.moinmo.in>`_

    MoinMoin is a wiki engine written in Python.

`pydap <https://pydap.github.io/pydap/>`_

    pydap is a modular and extensible `OPeNDAP <https://www.opendap.org/>`_
    server, used by the `IPCC <https://www.ipcc.ch/>`_ to serve climate model output.

`Roundup <https://www.roundup-tracker.org/>`_

    Roundup is a popular issue tracker which `includes WSGI support
    <https://www.roundup-tracker.org/docs/installation.html>`_.

`Trac <https://trac.edgewall.org/>`_

    Trac is a popular issue tracker.  It includes WSGI support in
    ``trac.web.wsgi``
